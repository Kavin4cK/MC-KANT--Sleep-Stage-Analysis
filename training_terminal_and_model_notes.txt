4) Model Details
==================================================
Model name in code:
- SleepCNN (1D CNN)

Input format:
- Per epoch shape before model: [channels, time]
- Converted from NPZ x with original shape [epochs, time, channels]

Architecture (high level):
- Conv1d( in_channels -> 32 ) + BN + ReLU + MaxPool
- Conv1d( 32 -> 64 ) + BN + ReLU + MaxPool
- Conv1d( 64 -> 128 ) + BN + ReLU + MaxPool
- Conv1d( 128 -> 256 ) + BN + ReLU + AdaptiveAvgPool1d(1)
- FC head: 256 -> 128 -> 5 classes with dropout

Classes:
- 0: W
- 1: N1
- 2: N2
- 3: N3
- 4: R

Loss/optimization:
- Class-weighted CrossEntropyLoss
- AdamW optimizer
- Gradient clipping (max norm 1.0)

Data split used in your final run:
- Subject-wise split: 80 train / 20 test
- val_size=0.0 (no validation split)
